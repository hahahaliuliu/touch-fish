# Downloadable Vocabulary Books

This directory contains vocabulary books that Touch Fish can download from its public catalog.

The following books are generated from [ECDICT](https://github.com/skywind3000/ECDICT):

- `high-school-vocabulary.json`: all valid English entries tagged `gk`, ordered alphabetically.
- `high-school-frequency.json`: the first 1,500 valid `gk` entries ordered by ECDICT's `frq` field.
- `cet4-frequency.json`: the first 1,500 valid `cet4` entries ordered by `frq`.
- `cet6-frequency.json`: the first 1,500 valid `cet6` entries ordered by `frq`.
- `ielts-frequency.json`: the first 1,500 valid `ielts` entries ordered by `frq`.

"High frequency" means this repository's frequency-ranked selection from ECDICT. It is not an official exam vocabulary list.
