# Touch Fish

Touch Fish 是一款伪装成终端（Terminal）的桌面学习工具。

它通过终端风格的界面，将学习内容伪装成命令输出，让用户能够阅读小说或学习单词。

## 项目目标

Touch Fish 的目标不是做一个复杂的阅读器，而是做一个可以长期使用、可以持续扩展的伪装学习工具。

第一版重点支持：

- 单词显示
- 小说阅读
- Terminal 风格界面
- 本地保存阅读进度
